# lattes-projects-extractor
Extração automatizada de projetos de ensino, pesquisa e extensão a partir de currículos Lattes utilizando Python e scriptLattes.
## ⚙️ Tecnologias
- Python
- scriptLattes
## 📊 Funcionalidades
- Extração automatizada de currículos Lattes
- Geração de planilhas com os projetos
- Organização por tipo: ensino, pesquisa e extensão
## ▶️ Como usar
1. Instale dependências
2. Configure e execute o scriptLattes para baixar os currículos dos pesquisadores
3. Salve todos os curríulos na mesma pasta do sript
4. Rode o script: 
```bash
python extrair_lattes.py
